# UnattendGenerator

Библиотека Кристофа Шнегганса, на которой работает генератор https://schneegans.de/windows/unattend-generator/.
Взята из https://github.com/cschneegans/unattend-generator (коммит 8a362f0, лицензия MIT — см. LICENSE.txt)
без изменений в коде; отличия от оригинала — только в файле проекта (одна целевая платформа, без Example.cs).

Раздел «Файл ответов» в WinStart строит `Configuration` этой библиотеки и получает тот же autounattend.xml, что и сайт.
