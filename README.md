# WinStart

Это моя программа для Windows 11. В ней собрано в одном окне то, что обычно делают после установки системы: убрать лишнее, ускорить, поставить нужные программы и навести порядок в автозагрузке. Ещё она готовит файл ответов для установочной флешки, и следующая установка Windows проходит сама, без вопросов.

## Как установить

Нужны Windows 11 и права администратора, больше ничего доустанавливать не нужно.

1. Скачайте `WinStartSetup.exe` со страницы [Releases](../../releases).
2. Запустите его и нажмите «Установить».

## Как пользоваться

Слева список разделов. Настройки Windows разложены по карточкам: одну можно применить сразу, а можно отметить несколько и нажать «Применить выбранные». Каждое изменение попадает в «Журнал», и большинство из них оттуда можно откатить. Нужное проще всего найти поиском по Ctrl+F.

В «Программах» 235 программ, они ставятся через winget, менеджер программ, который обычно уже есть в Windows 11. Раздел «Файл ответов» повторяет генератор с сайта schneegans.de, а готовый файл программа сверит с вашим образом Windows и запишет на флешку.

Новые версии WinStart ищет сам, а ставит по кнопке в разделе «Обновления». В «Настройках» можно включить бета-версии.

## Чего не умеет

Не всё можно вернуть: удаление Edge, Защитника и встроенных приложений, а также очистка необратимы, поэтому перед такими действиями программа предлагает создать точку восстановления. Программы ставятся только из каталога winget, без Microsoft Store. Раздел «Службы» работает на Windows 11 24H2 и новее. Загрузочную флешку WinStart не делает, файл ответов кладётся на уже готовую.

## Как собрать самому

Нужен .NET 10 SDK. В папке проекта выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File build/build-installer.ps1
```

Готовый установщик появится в `build/dist/WinStartSetup.exe`.
