# WinStart

Программа для Windows 11, которая собирает в одном окне всё, что обычно делают после установки системы: убрать лишнее, ускорить, поставить нужные программы и навести порядок в автозагрузке. А ещё она готовит файл для установочной флешки, чтобы следующая установка Windows прошла сама.

## Что умеет

- **Настройка Windows.** Разделы «Интерфейс», «Контекстное меню», «Очистка системы», «Оптимизация», «Установка ПО», «Компоненты». Каждое действие записывается в журнал, и большинство из них можно отменить одной кнопкой.
- **Файл ответов.** Заполняете форму — получаете файл `autounattend.xml`. Кладёте его на установочную флешку, и Windows ставится сама: с вашим языком, именем, учётной записью и без лишних приложений. Программа умеет проверить, подходит ли файл к вашему образу Windows, и сразу записать его на флешку.
- **Программы.** Браузеры, мессенджеры, архиваторы и другие популярные программы ставятся одной кнопкой. Тот же список можно добавить в файл ответов — тогда они установятся вместе с Windows.
- **Автозагрузка.** Показывает всё, что запускается вместе с Windows, и позволяет выключить лишнее.
- **Обслуживание.** Точка восстановления, проверка системных файлов, проверка диска, отчёт о компьютере.
- **Поиск по всей программе** (Ctrl+F), русский и английский язык, светлая и тёмная тема, обновление одной кнопкой.

## Установка

1. Скачайте `WinStartSetup.exe` со страницы [Releases](../../releases).
2. Запустите и нажмите «Установить».

Ничего доустанавливать не нужно. Программа работает на Windows 11 и запрашивает права администратора.

## Как собрать самому

Нужен .NET 10 SDK. В папке проекта выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File build/build-installer.ps1
```

Готовый установщик появится в `build/dist/WinStartSetup.exe`.
